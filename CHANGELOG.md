## 2026-05-28 — v2026.05.28.15 (TRY-токен выдаётся после оплаты Prodamus)

### Триггер

Антон: «токен выдаётся после удачной оплаты на Prodamus, ссылка на
оплату на сайте». Тест-драйв из бесплатного становится **платным
входом** (квалифицирует лида).

### Что изменилось

- **Установщик:** убрано слово «бесплатно» применительно к тест-драйву
  и токену (про бесплатную модель DeepSeek/opencode — осталось, она
  правда бесплатная). Доступ описан как «по токену после оплаты».
  Механизм токена НЕ менялся — установщику всё равно, как токен выдан,
  он только проверяет подпись.
- **Handoff-бриф (`handoff/trial-token-brief-for-techie.md`):** переписан
  под Prodamus. Токен генерится строго по подтверждённому webhook-у
  оплаты. Описаны 2 потока (через бота / ссылка на сайте + deep-link),
  оба сохраняют привязку токена к `tg_id` покупателя. Антифрод:
  проверка HMAC-подписи webhook Prodamus, идемпотентность.

## 2026-05-28 — v2026.05.28.14 (TRY-токен: доступ через бота)

### Триггер

Антон: «сделаем в тест-драйве такую же систему установки с токеном,
которую будем выдавать через бота». Цель — превратить бесплатный
тест-драйв в управляемый лид-канал: чтобы поставить, человек идёт к
@AITeamVIPBot за бесплатным TRY-токеном.

### Что добавилось

- **TRY-токен (новый тариф).** Формат `TRY-<hash16>-<tg_id>-<подпись>`,
  Ed25519, подпись над `TRY|<hash16>|<tg_id>`. Тот же ключ и механизм,
  что у платных тарифов (VIP/STD/SUB/HRM) — приватный ключ только у бота.
- **Двухфазный гейт** (т.к. node ставится на Шаге 1):
  - Фаза A (до установки) — формат + извлечение TG ID. Блокирует
    пустой/мусорный токен ДО любой установки.
  - Фаза B (после Node) — крипто-проверка подписи через node.
  Без валидного токена — стоп со ссылкой на @AITeamVIPBot.
- **TG ID из токена.** allowFrom настраивается на TG, зашитый в токен —
  клиента больше не спрашивают «напиши @userinfobot». Заодно анти-шаринг:
  бот ответит только тому, кому бот выдал токен.
- **Флаг `--token`/`--trial-token`** + env `TRIAL_TOKEN`. Кэш валидного
  токена в `~/.openclaw/trial-token` (chmod 600).

### Бот (отдельный код — технарю)

Бриф: `handoff/trial-token-brief-for-techie.md`. Бот должен выдавать
TRY-токены тем же Ed25519-ключом (новый payload `TRY|<hash>|<tg>`).

## 2026-05-28 — v2026.05.28.13 (выделение в отдельный репозиторий)

Тест-драйв установщик выделен из `openclaw-agents-pack` в собственный
репозиторий `openclaw-test-drive`. Код переехал как есть; `REPO_RAW`
теперь указывает на этот репо (шаблоны качаются отсюда).

### Возможности на момент выделения

- **Движок:** OpenClaw через `npm install -g openclaw@latest` + Node.js
  через nvm (кроссплатформенно). На macOS — авто-установка Xcode
  Command Line Tools с ожиданием в цикле.
- **nvm-персист:** прописывается в shell rc + `nvm alias default 22`,
  чтобы `openclaw` был доступен в новых терминалах.
- **Модель:** фиксированная бесплатная `opencode/deepseek-v4-flash-free`
  (без меню выбора). auth-profile пишется напрямую агенту.
- **Telegram:** `channels add` + `dmPolicy allowlist` + `allowFrom` +
  `bind telegram`.
- **Gateway:** `gateway.mode local` → `install` → `launchctl bootstrap`
  → `start`, проверка по надёжному маркеру `LaunchAgent (loaded)`.
- **onboard:** прогон `openclaw onboard --non-interactive` (best-effort,
  `</dev/null` против зависания) поверх проверенной ручной настройки.
- **Русский онбординг:** видимый чек-лист ✓/✗ по 5 узлам системы.
- **Финал:** авто-открытие страницы полной версии в браузере.
- **Флаги:** `--vps`, `--uninstall`/`--reset`, `--version`, `--help`.

### Инфраструктура

- `scripts/smoke-test.sh` — статические grep-проверки установщика.
- `scripts/security-audit.sh` — нет утечек секретов + чистые шаблоны.
- `scripts/update-checksums.sh` + `SHA256SUMS`.
- CI: ShellCheck, `bash -n`, smoke, security-audit, SHA256SUMS freshness.
